# Levy Exemptions

Exemption discounts apply as a percentage reduction of the full subtotal
(including any surcharge), applied after the surcharge and before the levy
is finalized. An exemption code must be declared on the shipment document
to be applied — it is never inferred. These two exemptions have applied
since the original 2024 schedule and remain in effect under the 2025-07
revision.

## DIPLOMATIC

Diplomatic cargo movements receive a full 100% levy waiver. Applies to all
cargo classes and vehicle classes. A shipment correctly declaring this code
owes no levy at all.

## AGRI-SUBSIDY

Shipments moving under the national agricultural subsidy program receive a
25% discount on the subtotal. Applies to general freight only — the code
has no effect if declared against perishable, hazardous, or oversized
cargo, since agricultural subsidy cargo is classified as general freight by
definition.
